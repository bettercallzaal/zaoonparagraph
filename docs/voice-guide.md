# Voice guide - running corrections log (durable copy)

Line-level corrections Zaal makes while working editions land first in the live
capture file `~/.zao/drafts/zaal-voice-guide.md`, then get folded here with the
before/after and the principle each one teaches. The voice compounds from real
edits, not guesses.

The mechanical rules are already enforced by `automation/check-voice.sh` and the
voice source of truth is `~/Documents/zabalgames/docs/newsletter-template.md` -
this file only holds judgment calls those cannot encode.

## Standing judgment calls

- Announcement vs daily voice is decided BEFORE drafting: a piece carrying a
  deadline, decision, or number that matters is an announcement - sentence case,
  numerals, real punctuation. The lowercase zero-comma staccato is daily-only.
  (Cost six rewrite passes on the Day 223 edition to learn.)
- The subtitle carries the news; the archive is the strongest receipt; name
  people over ranking them.
- Receipts over adjectives: a finalist line is built from their actual
  submission entries (titles, counts, live links), never from vibes.
